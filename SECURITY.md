# Security Policy

Report unsafe blueprints, leaked secrets, credential exposure, suspicious templates, unsafe rules, or vulnerabilities privately to the Clovaryn maintainers.

Do not open public issues for secrets or security vulnerabilities. Public reports can expose users before a fix is available.

If you find a package that includes credentials, private keys, unsafe Terraform generation, suspicious template behavior, or bypasses validation, report it privately with the package path, version, and a short description.
